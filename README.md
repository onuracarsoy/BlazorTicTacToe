📌 Proje Özeti

BlazorTicTacToe, Blazor Server ile geliştirilmiş basit ve interaktif bir XOX oyunudur.
Gerçek zamanlı güncellemeleri, komponent bazlı tasarımı ve temel oyun mantığını web ortamında gösterir.

✨ Özellikler

• Web tarayıcısı üzerinden Tic Tac Toe oynama

• Blazor komponentleri ile interaktif arayüz

• Aynı cihaz veya oturumda iki oyunculu mod

• Gerçek zamanlı güncellemeler

🛠️ Kullanılan Teknolojiler

• Blazor Server (.NET 8.0)

• C#

• SignalR WebSockets (opsiyonel, gerçek zamanlı için)

• Razor Components

🚀 Çalıştırma

1. Repoyu klonla:

git clone https://github.com/onuracarsoy/BlazorTicTacToe.git
cd BlazorTicTacToe


2. Solutionu Visual Studio ile aç

3. NuGet paketlerini geri yükle

4. Projeyi çalıştır (F5)
